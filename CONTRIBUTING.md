# Contributing

This is a hobby project: issues and small PRs are welcome, but there is no SLA
or roadmap.

- Bug reports: include your OS, Gleam/Erlang/Node versions, whether you are on
  Jira Cloud, steps to reproduce, and relevant logs with tokens, site URLs, and
  issue data redacted.
- PRs: keep them focused. Run the backend, shared, and UI test suites, run
  `gleam format` in each package, and if you change the UI, run `./build.sh`
  and commit the updated `assets/app.js`.
- Never paste API tokens, internal Jira URLs, or confidential issue content
  into an issue or PR.
- By submitting a PR you agree your contribution is licensed under the
  project's [MIT license](LICENSE).

Please be decent to each other.
